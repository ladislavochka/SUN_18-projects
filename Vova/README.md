# MyPythonProject — Продукти та виробники

Навчальний REST API на FastAPI. Початкову тему «Книги й автори» замінено на
«Продукти й виробники». Збережено реєстрацію, вхід через JWT і прив'язку
доданих записів до користувача.

## Можливості
- Реєстрація та вхід користувача.
- Перегляд списку виробників і продуктів.
- Додавання виробника (потрібна авторизація).
- Додавання продукту з вибором виробника (потрібна авторизація).
- Перегляд власних продуктів.
- Перегляд продукту та видалення власного продукту.
- SQLite база даних створюється автоматично.

## Запуск
Потрібен Python 3.10 або новіший.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Linux / macOS:
```bash
source .venv/bin/activate
```

Встановлення залежностей:
```bash
pip install -r requirements.txt
```

Запуск сервера:
```bash
uvicorn main:app --reload
```

Відкрийте документацію API: http://127.0.0.1:8000/docs

## Послідовність перевірки в /docs
1. `POST /auth/register` — створіть користувача.
2. `POST /auth/login` — натисніть Authorize і введіть username/password.
3. `POST /brands/` — створіть виробника, наприклад:
   `{"name":"Яготинське","country":"Україна","description":"Молочні продукти"}`
4. `GET /brands/` — подивіться список; запам'ятайте `id` виробника.
5. `POST /products/` — додайте продукт, наприклад:
   `{"name":"Молоко 2.5%","category":"Молочні продукти","price":45,"description":"Пастеризоване молоко","brand_id":1}`
6. `GET /products/` — перегляньте всі продукти разом із виробниками.
7. `GET /products/my` — перегляньте власні записи.

## Структура
- `main.py` — запуск FastAPI та підключення роутерів.
- `database.py` — підключення SQLite.
- `models.py` — таблиці User, Brand, Product.
- `schemas.py` — Pydantic-схеми запитів і відповідей.
- `auth.py` — хешування паролів і JWT.
- `routers/auth_router.py` — реєстрація та вхід.
- `routers/brands_router.py` — виробники.
- `routers/products_router.py` — продукти.
